# 多目录扫描调度

前端通过 `scan_music_dirs(paths)` 一次提交所选目录。Rust 按提交顺序逐个扫描；扫描单个目录也通过此接口提交一个路径。

- 同时只允许一个批次，第二个请求返回正在扫描的错误。
- `scan://batch` 推送当前目录、已完成目录数、目录总数和当前目录已扫描歌曲数。
- `cancel_scan_music_dir` 取消整个批次，终止正在运行的扫描进程；目录切换期间的取消标记不会被下一个目录清掉。
- 已完成目录的数据库结果保留；未完成扫描的目录不会执行扫描结果入库或缺失歌曲清理。
- 当前目录已经开始入库时，会完成这一步，然后停止后续目录。
- 批次遇到错误停止后续目录，前端刷新已经完成的曲库结果并显示错误。
- 扫描结束或取消后返回曲库与取消状态，最近添加由独立的后端查询提供；不再返回旧的 addedTracks / addedTrackIds，也不维护设置中的 lastAddedMusicDir / lastAddedTrackIds。
- 每个目录入库后不再查询并丢弃整份曲库；整批结束后统一查询。
