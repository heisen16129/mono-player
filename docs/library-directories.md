# 曲库目录管理

`update_library_directories({paths})` 接收最终目录列表，返回 `musicDirs`、`musicDir`、歌曲、最近添加歌曲及数量/总时长统计。

- 后端清理空路径、转换 file URL、规范化路径并按 Windows 路径规则去重。新增目录必须存在；已配置的离线目录可以继续保留或移除。
- SQLite 的 library_directories 表保存唯一目录配置。首次变更前读取旧设置中的目录；首次变更后以数据库为准，空列表不会回退为旧配置。
- 普通设置读取和保存均使用后端目录配置，前端旧设置不能覆盖目录。
- 目录配置、歌曲删除、收藏和歌单清理在同一个数据库事务中完成。失败回滚；不删除任何音乐文件。
- 数据提交后由已有后端播放器接口清理队列并保存会话，发送目录/收藏/歌单变更事件。
- 扫描期间拒绝修改目录，扫描入口通过后端注册并规范化待扫描目录；目录更新本身不启动扫描。
- 前端应用返回快照，保存失败时保留目录显示。旧 remove_music_dir 命令及前端逐目录删除逻辑已移除。

验证包含路径去重、旧设置保护、目录清空、事务失败时曲库/收藏/歌单回滚、扫描互斥，以及前端保存失败和扫描流程回归。未对用户实际曲库执行删除测试。
