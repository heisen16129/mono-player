# 下载记录

下载记录由后端保存在 SQLite 的 download_records 表。前端只读取列表并发送下载、暂停、继续、重试、清除记录及删除文件请求。

旧 downloads.items 数据首次启动时导入数据库，成功后移除旧 JSON 键。启动时未完成的下载标为中断，暂停记录保留；重启后继续会重新下载，不支持跨进程断点续传。

每次下载使用独立 run_id，忽略已删除记录及旧尝试的迟到事件。暂停通过下载工作进程在数据块之间等待；继续唤醒同一任务。网络请求阻塞时暂停不会立即打断请求。

清除记录保留已下载文件，活动任务会取消。删除本地下载由后端根据记录中的路径删除音频及歌词后移除记录。

列表查询必须提供 category：downloaded 仅返回完成记录，downloading 返回 downloading、paused、failed。SQL 按创建时间倒序返回，不分页。前端保留两类快照用于列表、下载标记及已下载播放队列，页面不再自行分类。
