# 播放会话

Rust 播放器负责保存当前歌曲、队列（含在线歌曲来源信息）、播放位置和播放模式。
SQLite `playback_session` 单行表保存整个会话快照；相同快照不重复写入。

- 切歌、队列修改、模式切换时保存；播放期间约每秒更新进度，暂停后拖动进度也保存。
- 正常退出时再次保存。强制结束进程时可能丢失最近约一秒的进度。
- 启动时前端读取后端返回的会话并调用已有的暂停队列恢复流程，不自动播放。
- 后端尚未初始化队列时不会覆盖已保存会话。启动期间用户已经开始播放则跳过恢复。
- SQLite 没有会话时，后端可读取原 JSON 会话；成功恢复后写入 SQLite，前端不再读写旧会话键。
- 在线歌曲保留 provider、sourceId、sourceRaw，播放时沿用已有来源解析流程。

播放栏继续播放统一调用 `player_resume`：已有音频时继续；仅恢复队列时由 Rust 加载当前歌曲并定位到保存进度。在线歌曲重新解析来源。前端恢复显示时不再发送停止命令，避免清空后端刚恢复的当前歌曲。
