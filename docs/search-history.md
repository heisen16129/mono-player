# 搜索历史

现有在线搜索历史由后端 `update_search_history` 管理，SQLite `search_history` 表保存关键词及递增顺序。

- `list` 返回最新历史；`record` 记录关键词；`remove` 删除单条；`clear` 清空。
- 后端修剪首尾空白，忽略空词及“热门歌曲”“热门歌手”，重复关键词移动到最前。
- 按设置保留 1–25 条，裁剪与修改在同一事务完成，每次返回最终列表。
- 前端只发送操作并显示返回值，串行请求防止保存、删除和清空互相覆盖。
- 启动时将 JSON `search.history` 导入空表，成功后删除旧键；已有数据库记录不被旧历史覆盖。
- 搜索历史仍在用户提交在线搜索时记录，不在输入过程中记录。
