# Mono 播放卡片

提供 14 种样式：极简、电影、杂志、票根、手账、便签、水墨、国风、古籍、黑胶、CD、拍立得、收据、瑞士排版。
在卡片右上角「卡片设置」中切换样式；主页面的选择会保存，并同步到已打开的桌面卡片。
桌面卡片切换样式后自动保存，重新打开或重启应用后恢复上次选择。
布局参考 BetterLyrics 同名 XAML 模板，以 344 × 480 排版、等比缩放为约 300 × 419 的实时播放卡片，而非静态分享长图。

导入本目录的 playback-card.monoplugin.zip，在歌词渲染器中选择「Mono 播放卡片」，点击播放器封面即可直接打开桌面右下角卡片，不进入歌词页。
卡片样式可在歌词渲染器设置中选择，也可在桌面卡片右上角设置中切换并保存。
需要包含桌面卡片支持的新版本 Mono；修改宿主后需重新启动 Tauri 应用。

卡片默认置顶、避开任务栏，显示封面、实时歌词、歌曲信息和播放进度。顶部可拖动，右上角关闭。
支持上一首、播放/暂停、下一首。退出歌词大页面后继续同步；退出 Mono 后卡片关闭。
每次重新打开默认回到当前屏幕右下角。无歌词时显示提示，不伪造逐字时间。

构建：`node plugin/playback-card/ui/build.mjs`。
浏览器预览：`/plugin/playback-card/ui/preview.html`；浏览器预览不创建桌面窗口。

1.2.0：按 BetterLyrics 原版的长卡片比例重新排版；显示最多四组歌词，相同时间戳的译文单独排在原文下方。控制按钮悬停或键盘聚焦时显示。

双语排版对照：`/plugins/playback-card/tests/gallery.html`。每款按可用空间显示 2～4 组歌词，避免译文超出卡片。

手账样式：米色活页纸、左侧装订孔和红色页边线，最多显示七组歌词，按空间自动减少。
