# BetterLyrics 歌词 · Mono 插件

1.2.0 起，扇形模式已拆为独立的「扇形歌词」插件：导入 `../fanlyrics/fanlyrics.monoplugin.zip` 即可安装。BetterLyrics 保留标准、辉光上浮、竖排、3D 透视；旧配置中的扇形选择回退为标准。两个插件的配置独立保存，原有自定义扇形参数不会自动迁移。

参考 [BetterLyrics dev](https://github.com/jayfunc/BetterLyrics/tree/dev) 的标准与窄屏歌词页面，
移植为 Mono 外置歌词渲染插件。直接使用 Mono 的歌曲、封面、歌词与播放时钟。

## 安装

1. 在 Mono「插件中心 → 订阅源」点击「导入插件」。
2. 选择本目录中的 `betterlyrics.monoplugin.zip`。
3. 在播放器设置的歌词渲染插件中选择「BetterLyrics 歌词」。

更新源码并重新构建后，需要重新导入安装包 才能更新已安装的副本。
无需修改或重新编译 Mono 宿主。

## 页面与操作

- 1.1.0 新增标准、辉光上浮、扇形、竖排、3D 透视五种样式。仅扩展呈现层，歌词解析和宿主协议不变。
- 在页面「显示设置 → 歌词样式」切换；选择辉光上浮会启用长音辉光与上浮预设，随后可独立修改强度和范围。
- 扇形角度支持 −45°～45°，透视角度支持 −45°～45°；辉光 0～24 px、上浮 0～16 px。
- 竖排歌词从上到下显示，滚轮横向浏览歌词列；切回横排自动重新定位当前行。

- 宽屏：左侧封面和歌曲信息，右侧聚焦歌词；700 px 以下改为顶部封面信息。
- 逐字填充高亮；700 ms 以上长音有发光、缩放和浮动效果。
- 500 ms 平滑定位，远处歌词模糊、缩小并淡出；尊重系统减少动态效果设置。
- 点击有时间戳的歌词跳转。滚轮/触摸浏览后 4 秒自动跟随，也可点击「回到当前歌词」。
- 鼠标移动时显示播放栏和顶栏，支持播放/暂停、上下曲、进度、音量、收藏、队列和搜索歌词。
- 底部播放栏右侧的显示设置可调整字号、行距、对齐、背景和各项动效；配置由 Mono 保存。
- 背景提供封面流动、封面模糊、跟随播放器。后者接收宿主纯色、图片、视频或原生 Scene 背景。
- 纯文本歌词保留手动浏览，不虚构逐字时间；暂无歌词时显示宿主的空状态或加载提示。

## 构建与验证

```powershell
node plugin/betterlyrics/ui/build.mjs
node --test plugins/betterlyrics/tests/state.test.mjs plugins/betterlyrics/tests/effects.test.mjs plugins/betterlyrics/tests/configEdits.test.mjs plugins/betterlyrics/tests/stylePresets.test.mjs
```

## 移植范围

这是歌词页面的网页移植，封面流动背景与 Win2D 动效为视觉近似，并非原程序逐像素复刻。
Mono 当前歌词协议没有独立的翻译/音译轨道：插件显示宿主给出的文本和逐字信息，
文本中已有换行时以次级字号显示后续行，不额外请求翻译服务。
原生桌面窗口、歌词卡片及 BetterLyrics 自身音源/歌词源不包含在本插件内。
