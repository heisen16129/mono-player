# 公共插件 API 迁移交付记录

日期：2026-10-21。

## 代码迁移结果

主程序公共 API 与 24 个插件的源码迁移已完成。不兼容旧插件；旧记录只允许移除或由新版安装覆盖，不通过兼容桥执行。

- 69 个公共方法已实现，方法、权限与参数约定见 `plugin-api-methods.md` 和 `plugin-api-v1.md`。
- 所有插件源码位于 `plugin/`；18 个 WASM 后端、6 个渲染模块、小爱页面与服务、人声分离页面均使用新版包及公共协议。
- 24 个安装包位于各自的 `plugin/<name>/` 目录，命名为 `<id>.monoplugin.zip`，内置商城索引位于 `plugin/dist/`，统一构建会重新生成包并调用原生校验器；WASM 清单由实际运行结果核对。
- 安装、更新、启停、卸载、批量操作、排序、权限确认、商城及订阅源均使用 v1 包。卸载保留用户配置、插件存储和已完成输出，撤销运行授权。
- 侧栏、播放栏及命令入口由插件自行声明。小爱申请播放栏入口，人声分离申请侧栏入口。
- 页面、歌词渲染器、桌面窗口统一通过 SDK 和隔离 MessagePort 调用宿主；旧专用桥、启动弹窗和运行入口已移除。
- 曲库、收藏、歌单、队列、播放、歌词、封面、搜索导入、临时媒体地址、配置存储、任务、事件及音频订阅均已接通。
- 停用、更新和撤权会终止失效会话、清理订阅并取消所属可取消任务；正常关闭页面不取消后台任务。
- 应用打包前自动构建小爱运行依赖和全部插件，避免使用旧产物。

## 运行验收边界

以上确认源码迁移、构建、协议回归和安装包有效性，未冒充真实桌面交互、需账号音源、实体小爱音箱和完整 Demucs 分离验收。`plugin/migration-status.json` 分别记录源码完成和实际运行验收状态；`releaseReady` 不因单元测试通过而自动置为 true。

未发布远端商城，未替换用户正在运行的插件安装记录。详细规则见 `plugin-rules.md`，改造落点见 `plugin-api-migration-plan.md`。

## 2026-10-22 目录统一

后端源码和 Cargo 配置移入 backend/；页面、渲染器及其源码移入 ui/。编译好的 WASM 统一输出 dist/plugin.wasm，小爱服务输出 dist/service.mjs，Vue 页面输出 ui/dist/。各插件清单、宿主嵌入路径、构建与测试入口同步调整。安装包保留源码和运行文件的原路径，排除 node_modules、target 和缓存；安装包名称和位置继续为各插件根目录下的 <id>.monoplugin.zip。

## 2026-10-22 移除小爱 WASM 薄层

小爱删除 entry.wasm、backend/wasm/ 和 dist/plugin.wasm。宿主完成身份和权限校验后，直接启动 entry.service，不再调用 speaker_service 固定标记。构建与运行类型显示同步改为 Node 服务；17 个实际使用 WASM 的插件保持原有运行方式。小爱保留原插件 ID 以避免配置和存储身份变化。安装包及目录索引暂不重新生成，发布产物尚未包含此项改动。

## 2026-10-22 恢复小爱弹窗

小爱使用统一插件页面容器在主窗口覆盖弹窗中打开，关闭只销毁页面会话，不停止 Node 服务。页面声明支持 presentation: dialog/page；未声明时，侧栏入口默认主内容页，播放栏入口默认弹窗；插件显式声明优先，不依据后端运行方式决定。播放栏入口和插件管理页入口共用同一弹窗，普通插件页面布局不变。安装包暂不更新。

## 2026-10-22 分离实现迁回插件

分离环境准备、Demucs worker、批次执行、进度、取消及输出缓存移到 plugin/stem-separation/backend/。
分离插件声明 Node service 入口，不再携带仅返回分离计划的 WASM。公共 SDK 删除 separation 和只服务该功能的 tasks，增加通用 service.getConnection、files.choose、files.reveal。
宿主保留服务进程管理、原生文件对话框，以及 K 歌切换播放所需的适配调用；不再包含 Demucs 引擎、模型或环境安装逻辑。
插件数据位于应用数据目录的 plugin-data/<插件ID>/，环境、模型及输出由插件管理；旧缓存不自动迁移。小爱保持原有实现。
