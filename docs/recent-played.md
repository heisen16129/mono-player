# 最近播放

`tracks.last_played_at` 为可空的 Unix 毫秒时间戳。新增扫描记录默认为 NULL，重新扫描不覆盖已有播放时间，旧数据库升级时也不会凭空生成播放时间。

Rust 音频状态监听器在歌曲开始播放或恢复播放时更新时间，同一首歌持续播放不会随进度刷新反复写库。仅恢复暂停的播放会话、缓冲中、播放失败均不记录。小爱音箱的播放通知使用同一数据层更新。

`list_recently_played_tracks` 查询时间非空的曲库歌曲，按 `last_played_at DESC, id DESC` 返回，由后端限制最多返回 100 首，不删除更早的播放时间，不再使用 JSON ID 列表。前端监听 `recently-played-changed` 后重新查询，搜索筛选不改变后端返回的顺序。

只记录歌曲表中已有的歌曲；未入库的在线歌曲不会额外插入曲库。移除曲库记录时，其最近播放记录随歌曲一起移除。
