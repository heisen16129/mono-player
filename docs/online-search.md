# 在线音乐搜索

界面仍只搜索选中的来源。search_online_music 从后端读取该插件和配置，查询固定每页 30 条的插件结果。

首次搜索返回 sessionId；加载更多携带同一标识。后端维护当前关键词、来源、页码、完整结果及结束状态，以来源 ID + 歌曲 ID 去重，保留首次出现顺序。每次响应提供完整列表，前端直接展示。

重复页最多连续跳过三页，保存已读页码；没有新歌曲并不表示结束。插件返回结束标识或空页才结束。失败时保留原列表和页码，允许重试。

新搜索替换旧会话，旧结果不能提交；前端同样忽略过期响应。当前会话仅保存在内存中，不写入 SQLite；搜索历史仍使用原有数据库功能。歌词搜索使用独立的 search_online_lyrics 接口和内存会话，共用去重、翻页和结束判断规则。歌词搜索失败保留已加载结果及页码，可重试；前端负责展示错误。封面搜索仍为独立单页查询，不替换歌词搜索会话。
