# 曲库搜索

`search_library(query)` 从 SQLite 读取曲库、最近添加、最近播放三个列表，由 Rust 统一执行搜索并返回完整匹配结果，不分页。

- 匹配歌名、歌手、专辑；忽略首尾空白及大小写，按普通子串匹配（`%`、`_` 不作为通配符）。
- 曲库保留添加时间倒序。
- 最近添加保留最新添加日期对应扫描批次的规则，搜索不改变批次范围。
- 最近播放先按最近播放时间倒序取最新 100 首，再在这 100 首中搜索。
- 目录、歌手统计复用相同搜索规则。
- 搜索框输入只更新草稿，按回车后提交搜索词；清空输入并按回车恢复完整列表。曲库、扫描结果或播放历史变化时按已提交的搜索词刷新；100ms 合并连续变更，旧请求不会覆盖新结果。
- 侧栏最近添加、最近播放显示未搜索的列表总数，不随搜索结果变化。
- 收藏、用户歌单沿用各自现有逻辑。

查询同时返回 `statistics`（匹配结果统计）及 `totals`（未搜索的列表统计），每组包含 `count`、`totalSeconds`。最近播放统计范围仍最多为最新 100 首。未知时长计 0 秒，空列表为 0 首、0 秒。收藏接口返回 `items` 与 `statistics`，每个歌单也包含 `statistics`；曲库元数据变化后重新查询收藏与歌单统计。前端仅负责秒数转时分的显示。
